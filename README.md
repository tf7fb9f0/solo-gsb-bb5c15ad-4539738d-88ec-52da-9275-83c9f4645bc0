# 事件时序约束校验（Timeline Constraint Checker）

面向采访记录、事故复盘等场景的事件时序一致性校验工具。用户以「事件 A 比事件 B 早 / 晚 x ~ y 分钟」的形式录入约束并指定一个锚点时间，系统将约束转为**差分约束图**并实时判断是否可满足：

- **出现矛盾**：基于 Bellman-Ford 负环检测，突出显示一条可复核的矛盾环（环上每条不等式及其来源约束、求和结果），并在约束列表中高亮涉及的约束；
- **可满足**：计算每个事件相对锚点的最早 / 最晚时间窗；未与锚点在约束图中连通的事件标记为「无法定时」；
- 内置两组示例数据（可满足 / 含矛盾），所有数据自动持久化到浏览器 localStorage。

技术栈：React 18 + TypeScript + Vite，无任何后端依赖。

## 使用说明

1. **锚点设置**：选择（或输入）锚点事件并指定其发生时间，作为推算其他事件时间的基准。
2. **添加约束**：填写事件 A、关系（早于 / 晚于）、分钟数下限与上限、事件 B。例如「值班员接警 比 报警触发 晚 2 ~ 5 分钟」。
3. **查看结果**（右侧面板实时更新）：
   - 绿色「约束可满足」：表格列出每个事件的最早 / 最晚绝对时间及相对锚点的偏移；与锚点不连通的事件标记为「无法定时」；
   - 红色「约束不可满足」：展示一条矛盾环——沿环的不等式链条、每条不等式来源的原始约束，以及求和得到的 `0 ≤ 负数` 矛盾式，便于逐条复核。
4. **示例数据**：一键加载「事故复盘（可满足）」或「口供冲突（含矛盾）」示例，便于快速体验两种结果形态。

## 算法简介

每条约束统一建模为 `A - B ∈ [low, high]`（分钟），拆成两条差分约束边：

- `A ≤ B + high` ⇒ 有向边 `B → A`，权重 `high`
- `B ≤ A - low` ⇒ 有向边 `A → B`，权重 `-low`

- **可满足性**：差分约束系统无可行解当且仅当约束图存在负权环。用 Bellman-Ford（所有节点距离初始化为 0，等价于超级源点，可覆盖不连通子图）检测负环，并沿前驱指针回溯提取环上的事件与不等式。
- **时间窗**：以锚点为源点求单源最短路，`dist(anchor → v)` 给出 v 的最晚偏移；在反向图上求最短路得到 `dist(v → anchor)`，其相反数给出最早偏移。两侧均不可达的事件与锚点不连通，标记为「无法定时」。
